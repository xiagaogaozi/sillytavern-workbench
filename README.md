# 酒馆工作台 (SillyTavern Workbench)

> **v0.7.2** · 适用于 SillyTavern 的一体化管理工作台扩展，采用 SPreset Editor 风格多标签三栏引擎，集 **预设、世界书、角色卡、聊天记录、数据库 1.3.x** 与 **AI 编辑助手** 于一体。零构建依赖，关闭即零后台占用。

## 核心功能

### 1. 预设与 SPreset 编辑
- 完整保留 `prompts`、`prompt_order`、第三方未知字段与 `extensions`（含 SPreset 条件、工具绑定与结构化消息字段）。
- 顺序流程 / 自动注入分区查看、拖拽排序、跨预设复制、搜索高亮与全局查找替换、Token 统计。

### 2. 世界书全量编辑与极速性能
- 蓝灯 / 绿灯 / 向量化一键 SVG 切换，支持粘性 / 冷却 / 延迟 / 分组 / 互斥 / 递归控制等全套高级字段。
- 支持 YAML / JSON 导入导出、格式清理、关键词修复、深度合并、主书 / 附加书 / 当前聊天 / 全局绑定管理。
- Copy-on-Write 结构共享编辑 + 分批窗口渲染，万行大世界书毫秒级响应。

### 3. 角色卡管理
- 左栏实时检索与三种排序（字母 / 导入时间 / 最近游玩）、批量选择器（选择 / 全选 / 批量删除，默认不删聊天防误删）。
- 编辑角色描述、主开场白、备选开场白（增删排、跨卡复制）与全套 V2 属性字段，完整保留第三方扩展字段。
- 支持修改头像图片、修改绑定世界书（主书 + 附加书）与一键跳转、修改酒馆标签、PNG/JSON 导出、导入与原位更新角色卡（保留原聊天与标签）。

### 4. 聊天记录管理
- 支持全酒馆所有角色聊天汇总（默认按角色分类，切换排序后统一排序），也可从角色卡直接进入查看该角色全部聊天。
- 批量选择与删除、导入（`.jsonl` / `.json` / `.txt`）与导出（**TXT 纯文本版** / **标准 `.jsonl` 聊天记录版**）。
- 自动探测中英文及嵌套 XML/HTML 标签频次，**选择标签（仅提取）与排除标签（彻底剔除）同时生效**。
- 右侧按楼层分页预览，支持楼层关键词高亮跳转、直接手动编辑内容、还原为标签筛选结果与安全保存写回。

### 5. 数据库（shujuku 1.3.x 直连）
- 直连管理 **剧情推进、表格模板（含 SQL / DDL / 种子行 / 索引）、正文替换** 及 **7 类数据库提示词预设**。
- 支持预览差异后备份并应用，以及数据库功能模块总开关管理。

### 6. 双条目三栏对比与 AI 编辑助手
- 支持预设 / 世界书 / 数据库双文档同屏并排 Diff 对照与选择性合并覆盖（角色卡与聊天记录不参与双对比）。
- 内置 AI 编辑助手：支持复用水酒馆主 API 或独立渠道，先审阅提案后一键采纳进草稿。

### 7. 严格隐私与零占用设计
- 关闭工作台即销毁 `iframe` 与所有事件监听，后台零轮询、零常驻内存占用。
- 所有编辑器修改先入草稿栈并支持撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`），保存及破坏性操作前自动通过酒馆原生机制创建备份。

## 安装方式

### 通过 SillyTavern UI 安装
1. 打开 SillyTavern → **扩展 (Extensions)** → **安装扩展 (Install extension)**。
2. 填入仓库地址：
   ```
   https://github.com/xiagaogaozi/sillytavern-workbench
   ```
3. 安装完成后刷新页面，在聊天输入框旁的 **扩展菜单 → 酒馆工作台** 打开即可。

### 手动安装
将仓库克隆到 SillyTavern 用户扩展目录（例如 `data/<你的用户名>/extensions/sillytavern-workbench`）：
```bash
git clone https://github.com/xiagaogaozi/sillytavern-workbench.git
```
刷新浏览器即可使用，无需 `npm install` 或额外打包步骤。
