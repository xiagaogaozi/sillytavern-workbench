## 兼容和范围说明

- SPreset附加功能及资源库界面按要求排除，但不删除原预设里相关数据。
- 世界书工作台与预设使用统一交互，不注入原工具整包脚本。关闭窗口保留工作区，等价于收起工作台。
- 原工具的浏览器设置不会自动搬迁。新工具设置有独立命名空间；原世界书文件夹元数据与原YAML/项目文件通过明确导入处理。
- 本版不改写聊天生成链；特殊提示词运行由SPreset承担，世界书实际触发由酒馆原生引擎承担。
- 项目、草稿与会话按浏览器保存；配置保存在酒馆原生用户文件中，原生设置命名空间保留镜像，不提供跨设备实时共同编辑。
